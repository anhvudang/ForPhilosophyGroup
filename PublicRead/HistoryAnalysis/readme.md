# How to read

## EN

Each folder contains a `main.md` file that summarizes that period of time. The file links to other supporting files in the same folder.

All files are AI-generated and may contain misinformation or oversimplified information.


## VI

Mỗi thư mục chứa một tệp `main.md` tóm tắt khoảng thời gian đó. Tệp này liên kết đến các tệp hỗ trợ khác trong cùng thư mục.

Tất cả các tệp đều được tạo bởi AI và có thể chứa thông tin sai lệch hoặc thông tin được đơn giản hóa quá mức.
